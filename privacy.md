# Privacy Policy

**App:** The Working Behind Uploader
**Last updated:** 28 October 2026

## Who uses this app

The Working Behind Uploader is a private desktop tool. It is used only by the owner of The Working Behind YouTube channel and Instagram account, on the owner's own computer, to upload the owner's own videos. It has no other users.

## Use of YouTube API Services

This app uses YouTube API Services. By using it, you agree to the [YouTube Terms of Service](https://www.youtube.com/t/terms). Your data is also handled under the [Google Privacy Policy](https://policies.google.com/privacy).

## What data the app accesses

When the owner signs in with Google, the app requests the `youtube.upload` permission. It uses it only to:

- upload videos to the owner's own YouTube channel, and
- set each video's title, description, tags, category, audience setting and scheduled publish time.

The app does not read, collect or use any other Google account data, and it does not access other people's channels or data.

## How data is stored

- The Google sign-in token is stored only on the owner's computer, in a local file.
- Video files, titles, descriptions and schedules are stored only on the owner's computer.
- Nothing is stored on any external server run by this app.

## Sharing

The app does not share, sell or transfer any data to anyone. Data is sent only to YouTube (and Instagram) to publish the owner's own videos.

## Revoking access and deleting data

Access can be revoked at any time from the [Google security settings page](https://myaccount.google.com/permissions). Deleting the app's local token file removes all stored sign-in data from the computer.
